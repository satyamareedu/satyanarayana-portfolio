A responsive Swiss-modernist portfolio website for Satyanarayana Mareedu, Java Full Stack Developer.

## Structure

- `index.html` — portfolio content and semantic page structure
- `styles.css` — responsive Swiss-modernist visual system
- `script.js` — mobile navigation and current year
- `assets/profile.png` — uploaded professional photo

## Run locally

No build tools are required.

1. Open the folder in VS Code.
2. Open `index.html` in a browser.

For a local development server, you can use VS Code Live Server or any static HTTP server.

## Deploy

This is a static site and can be deployed to GitHub Pages, Vercel, Netlify, or another static host.
